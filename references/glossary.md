# 术语隔离表

本篇列出 skill 内部设计叫法与产品对外文案的对应关系。

设计词汇仅用于 AI 理解规则，禁止直接出现在最终用户的操作界面或文档中。

| 内部设计术语 | 含义 | 对用户展示时的叫法 |
| --- | --- | --- |
| 联觉终端 | 控制台或后台管理界面 | 工作台、控制台、数据中心 |
| 数据坞 | 数据库或资产列表 | 资源库、资产清单、记录总览 |
| 频段采样 | 列表记录或数据行 | 记录、数据项、监控样本 |
| 谐波稳态 | 系统运行状态或健康度 | 运行正常、已同步、健康度 |
| 衍射金高亮 | 主操作按钮或选中项 | 保存、确定、查看详情 |
| 湮灭过载 | 危险操作或删除 | 删除该项、清除缓存、解除绑定 |
