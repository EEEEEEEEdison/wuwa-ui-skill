# 术语隔离表

本篇列出 skill 内部设计叫法与产品对外文案的对应关系。

设计词汇只用于让 AI 理解规则，不得直接出现在最终用户的界面或文档中。

| 内部设计术语 | 含义 | 对用户展示时的叫法 |
| --- | --- | --- |
| 流金实底按钮 | 主操作 | 开始、保存、确定 |
| 炭黑金边按钮 | 次要操作 | 查看记录、打开目录 |
| 细线按钮 | 普通操作 | 刷新、选择文件 |
| 危险细线按钮 | 不可恢复的操作 | 删除队伍、清除缓存 |
| 左金条卡片 | 当前最重要的状态区 | 按内容命名，如“自动战斗” |
| 眉标 | 页面标题上方的英文标签 | 与页面标题同义的英文，如 `PREFERENCES` 对应“设置” |
| 状态圆点 | 运行状态指示 | 运行中、已连接、已停止、运行失败 |
| 玄黑主题 / 象牙主题 | 深色 / 浅色主题 | 深色、浅色、跟随系统 |
