# 做与不做

本篇规定《鸣潮》官网风味界面的制作细则。

## 做

- 底色以纯黑 `#000000` 与半透炭黑 `rgba(33, 33, 33, 0.5)` 为主。
- 主强调色必须使用流金系：`#C4AC7D` 与 `#C9AC67`。
- 大标题使用明亮流金 `#DAB67D`，辅以暖砂白 `#D3CBB8`。
- 采用对角圆角：左上与右下圆弧，右上与左下直角（`border-radius: 16px 0;`）。
- 按钮采用非对称粗金边：底部与右侧带有 3px 实体金边。
- 卡片采用非对称边框：左侧带有 4px 粗金边，上下配 1px 细银线。
- 西文字标使用全大写宽体无衬线字体，字距舒展。
- 列表项使用 1px 细线 `#505050` 分割。悬停时文字变为金色，整行带有微光滑动。

## 不做

| 不做 | 为什么 |
| --- | --- |
| 蓝绿霓虹光晕与刺眼青色 | 官网是末世诗意与流金质感，不属于赛博朋克。 |
| 高饱和柠檬黄 | 官网使用的是低饱和哑光香槟流金 `#C4AC7D`。 |
| 对称纯切角（45° 单一切角） | 官网使用的是对角圆角矩形与直角交错。 |
| 厚重机械仪表盘与示波器大屏 | 官网版式空灵简洁，以优雅内容展示为主。 |
| 假技术乱码与条形码 | 增加多余视觉噪音，破坏高级感。 |
