# 做与不做

本篇规定《鸣潮》官网风格界面的制作细则。色值与尺寸见 `tokens.md`。

## 做

- 底色以纯黑 `#000000` 与半透炭黑 `rgba(33, 33, 33, 0.55)` 为主。
- 主强调色必须使用流金系：`#C4AC7D` 与 `#C9AC67`。
- 大标题使用明亮流金 `#DAB67D`，辅以暖砂白 `#D3CBB8`。
- 采用对角圆角：卡片圆弧在左上与右下（`border-radius: 16px 0;`），流金按钮与输入框圆弧在右上与左下（`0 10px`）。
- 主操作按钮用流金实底、深色文字（`#16130E`），对角圆角 `0 10px`。
- 次要按钮用炭黑底，底部与右侧带有 3px 实体金边。
- 普通操作用透明底加 1px 中性细线，悬停时边框与文字变为流金。危险操作用危险色文字加 1px 同色细线。
- 重点卡片左侧带有 4px 粗金边，上下配 1px 细线。
- 页面标题上方可放一个英文眉标，使用全大写宽体无衬线字体，字距舒展。段落标题只写中文。
- 列表项使用 1px 细线 `#505050` 分割。悬停时文字变为金色，整行带有微光滑动。
- 状态使用 8px 圆点加文字：运行为流金，正常为 `ok`，等待为 `warn`，失败为 `danger`，停止为弱化灰。
- 表单标签在输入框上方，说明文字在下方，使用弱化色。
- 正文 14px；说明、表头与表单标签不小于 13px，眉标不小于 12px。信息放不下时调整布局，不缩小字号。
- 空列表显示一句居中的说明，告诉用户下一步怎么做。

## 不做

| 不做 | 为什么 |
| --- | --- |
| 蓝绿霓虹光晕与刺眼青色 | 官网是末世诗意与流金质感，不属于赛博朋克。 |
| 高饱和柠檬黄 | 官网使用的是低饱和哑光香槟流金 `#C4AC7D`。 |
| 对称纯切角（45° 单一切角） | 官网使用的是对角圆角矩形与直角交错。 |
| 厚重机械仪表盘与示波器大屏 | 官网版式空灵简洁，以优雅内容展示为主。 |
| 假技术乱码与条形码 | 增加多余视觉噪音，破坏高级感。 |
| 每个区块都包进实底灰框 | 页面变重，层级被灰框淹没。用细线与留白分组。 |
| 用小字做装饰：段落眉标、导航英文副标题、标语、徽标 | 增加阅读负担，画面变碎。每页最多保留一个页头眉标。 |
| 每个按钮都描金边 | 金色失去指向。普通按钮用中性细线，金色只留给主操作与当前位置。 |
| 一排同样大小的灰色按钮 | 用户分不清主次。按“流金实底、金边、细线”分三级。 |
| 拉满整行宽度的按钮 | 桌面窗口很宽时按钮失去比例。按钮宽度跟随文字。 |
| 浅色主题中流金实底配白字 | 对比度约 2.8:1，低于正文最低要求 4.5:1。 |
| 系统默认的白色复选框、亮色标题栏 | 与深色界面冲突。复选框与标题栏必须跟随主题。 |

## 桌面应用补充

- 窗口标题栏必须跟随主题：深色主题使用深色标题栏。
- 侧栏导航选中项使用左侧 3px 金条、金色文字与淡金底；悬停只改变文字颜色。
- 可点击控件的高度不宜低于 32px，键盘焦点必须可见（1px 金线）。
- 状态栏放在内容区底部，用 1px 细线与内容分开，只显示最近一条结果。
- 必须在 100%、150%、200% 缩放下检查文字截断与换行。
