# 调研：鸣潮官网的真正界面语言

本篇记录对《鸣潮》官方网站（mc.kurogames.com）样式表的实测解构。数据全部来自官网生产环境样式表（`index-9728d3f2.css` 与 `useNewsData-8fe7a02b.css`）。

## 1. 颜色与材质实测

| 用途 | 实测色值 | 样式表出处与用法 |
| --- | --- | --- |
| 官网底色 | `#000000` 纯黑 | 页面与视频背景底色 |
| 核心流金 | `#C4AC7D` | 【测】按钮背景、激活滑块、悬停高光 |
| 边框浅金 | `#C9AC67` | 【测】主要边框线、标题高亮、浮动标签 |
| 标题亮金 | `#DAB67D` | 【测】大标题 `.page-title` |
| 暖砂象牙白 | `#D3CBB8` `#D2CAB8` | 【测】副标题、分割细线、说明文字 |
| 银白文字 | `#E1E1E1` | 【测】导航未激活项、文章正文 |
| 炭黑底块 | `#2A2A2A` `#3A3434` | 【测】深色按钮表面、下拉菜单项 |
| 分隔微线 | `#505050` `#616161` | 【测】列表分割线、细下划线 |

结论：官网绝非蓝绿霓虹或刺眼亮黄。官网的核心气质是“玄黑配哑光流金（#C4AC7D）、暖砂象牙白与银灰”。整体调性偏向电影感、末世诗意与古典人文科幻。

## 2. 几何与边框实测

- 【测】对角圆角矩形：官网标志性形状为对角圆弧（如 `border-radius: 20px 0;` 或 `border-radius: 0 10px;`）。一组对角为圆弧，另一组对角为直角：`20px 0` 的圆弧在左上与右下，`0 10px` 的圆弧在右上与左下。
- 【测】非对称金边：按钮常带有单侧或双侧粗金边（如 `border-bottom: 3px solid #C4AC7D; border-right: 3px solid #C4AC7D;`）。
- 【测】左侧指示金条：如 `.banner` 带有 `border-left: 4px solid #C9AC67;`，上下配 1px 细银线。
- 【测】极细下划线：标签切换条 `.tab-navi` 仅高 3px，底色为 `#C4AC7D`。

## 3. 字体实测

- 【测】西文主字体：官网使用 **`Novecentowide-Medium`** 与 **`Novecentowide-Bold`**。全大写宽体无衬线，字间距舒展。
- 【测】中文主字体：官网使用 **`mc-gamefont`**（定制汉仪重黑体）配 **`Noto Sans SC`**（思源黑体）。
- 【测】时间戳排版：日期如 `2026.11.06` 统一采用 `Novecentowide`，字号较小，颜色为 `#989898`。

## 4. 减法与取舍

| 采用 | 不采用 |
| --- | --- |
| 纯黑玄岩底、哑光流金、暖砂象牙白 | 蓝绿霓虹光、高饱和柠檬黄、赛博朋克大外发光 |
| 对角圆角矩形、非对称粗金边、极细银线 | 通用 45° 纯切角、厚重金属边框、方格仪表盘 |
| Novecentowide 宽体大写英文字 | 粗糙等宽代码字体作为大标题 |
| 淡雅水波涟漪、滑动下划线 | 持续剧烈晃动、刺眼粒子噪点 |
