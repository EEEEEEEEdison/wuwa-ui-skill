# 设计令牌（Tokens）

本篇说明 `assets/tokens.json` 中的定义。深色主题数值从《鸣潮》官网样式表测算；浅色主题、状态色与动效为本 skill 补充，已通过 `scripts/check-contrast.mjs` 检查。

## 1. 颜色规范

### 核心流金色阶（Champagne Gold）

| 令牌 | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `gold` | `#C4AC7D` | `#B5986A` | 主按钮底、选中指示条、悬停高光 |
| `goldBorder` | `#C9AC67` | `#C4AC7D` | 边框线与标签边线 |
| `goldTitle` | `#DAB67D` | `#8E7340` | 页面大标题（24px 以上） |
| `goldText` | `#C4AC7D` | `#7A6233` | 金色文字：选中导航、链接、悬停中的按钮文字 |
| `onGold` | `#16130E` | `#16130E` | 流金实底上的文字 |

浅色主题的金色文字必须用 `goldText`。`gold` 作为文字时对比度约 2.5:1，只能用于填充和线条。

### 矿物暖砂与银白色阶（Mineral Sand & Silver）

| 令牌 | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `silver` | `#E1E1E1` | `#242220` | 正文、未激活导航 |
| `sand` | `#D3CBB8` | `#70685C` | 副标题、眉标、表单标签 |
| `textMuted` | `#989898` | `#6E665A` | 时间戳、说明文字 |

### 底板与深炭阶梯（Obsidian & Charcoal）

| 令牌 | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `bg` | `#000000` | `#F7F5F0` | 页面底色 |
| `surface` | `rgba(33, 33, 33, 0.55)` | `rgba(255, 255, 255, 0.92)` | 半透卡片 |
| `surfaceSolid` | `#1A1A1A` | `#FFFFFF` | 侧栏、弹层等不透明面 |
| `surfaceRaised` / `onRaised` | `#2A2A2A` / `#E1E1E1` | `#242220` / `#FFFFFF` | 炭黑次要按钮及其文字 |
| `input` | `#121212` | `#FFFFFF` | 输入框底色 |
| `borderLine` | `#505050` | `#D2CAB8` | 分区细线、表头下线 |
| `borderSoft` | `#2E2E2E` | `#E7E2D7` | 表格行线等次级细线 |
| `selected` | 流金 12% 透明 | 流金 16% 透明 | 选中行、选中导航底色 |

### 状态色

| 令牌 | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `ok` | `#9DBB86` | `#4E7A36` | 已连接、通过 |
| `warn` | `#D9A55B` | `#8C5B12` | 等待、权限不足 |
| `danger` | `#E07A6E` | `#B0453A` | 失败、删除 |

状态色只能用于圆点、短文字与细线，不得用作大面积底色。“运行中”使用 `gold`。

## 2. 标志性几何尺寸

| 名称 | CSS | WPF `CornerRadius` / `BorderThickness` |
| --- | --- | --- |
| 卡片对角圆角 | `border-radius: 16px 0;` | `16,0,16,0` |
| 小号对角圆角 | `border-radius: 0 10px;` | `0,10,0,10` |
| 炭黑按钮圆角 | `border-radius: 18px 0;` | `18,0,18,0` |
| 炭黑按钮金边 | `border-bottom/right: 3px` | `0,0,3,3` |
| 左侧指示金条 | `border-left: 4px` | 单独的 4px 宽色块 |
| 底部指示滑块 | 高 `3px` | 高 3 的色块 |

CSS 圆角简写的顺序是左上、右上、右下、左下；WPF `CornerRadius` 的顺序也是左上、右上、右下、左下，所以 `16px 0` 换算为 `16,0,16,0`。

## 3. 字体配置

- 西文大标题与数字：优先使用 `Novecento Wide`，网页端回退到 `Cinzel`、`Saira` 或 `Barlow Semi Condensed`。Windows 桌面使用系统自带的 `Bahnschrift`。
- 中文标题与正文：网页使用 `Noto Sans SC`（思源黑体）与系统黑体；Windows 桌面使用 `Microsoft YaHei UI`。

| 层级 | 字号 | 字重 |
| --- | --- | --- |
| 页面眉标 | 13px，大写，字距 0.2em，每页最多一个 | 常规 |
| 页面标题 | 30px（桌面）至 38px（网页） | 粗体 |
| 段落标题 | 17px | 粗体 |
| 正文 | 14px，行高 1.6 | 常规 |
| 说明、表头、表单标签 | 13px | 常规 |

字号下限：说明、表头与表单标签不小于 13px，眉标不小于 12px。信息放不下时调整布局或折行，不缩小字号。

## 4. 间距与动效

- 间距只用 4、8、12、16、24、32、48 七档。
- 悬停过渡 200 毫秒；入场不超过 520 毫秒；缓动 `cubic-bezier(0.2, 0, 0, 1)`。
